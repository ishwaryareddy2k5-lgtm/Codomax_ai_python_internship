Student Grade Calculator

Project Overview

A beginner-friendly Python mini project that calculates a student's total marks, percentage, and grade.

Features

- Accepts a student's name.
- Takes marks for three subjects.
- Calculates total marks and percentage.
- Assigns a grade based on the percentage.
- Checks that marks are within the range of 0–100.

Technologies Used

- Python 3

Concepts Learned

- Variables and user input
- Lists and loops
- Conditional statements
- Arithmetic operations
- Basic input validation

How to Run

1. Install Python 3.
2. Open a terminal in the project folder.
3. Run "python main.py".
4. Enter the student name and marks when prompted.

Learning Outcome

This project helped me practise basic Python programming and understand how to build a simple program using user input, calculations, and conditions.
